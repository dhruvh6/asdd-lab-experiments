# Experiment 1 — Version Control Operations Using Git

**Aim:** To understand and perform basic version control operations using Git.
**LO2:** Use git effectively for version control, source management and collaborative team development.

| File | Contents |
|---|---|
| `commands.ps1` | Every Git command run in the experiment, in order (PowerShell) |
| `screenshots/` | Terminal output of each command (01–25) |
| `Exp1_Report.pdf` | Report |

Operations covered: `config`, `init`, `status`, `add`, `commit`, `diff`, `commit -a`,
`log --oneline`, `branch`, `switch`, `merge`, `remote add`, `commit --amend`,
`reset --soft`, `revert`, `push -u`, `mv`, `rm --cached`, `stash` / `stash list` / `stash pop`,
`remote -v`, `branch -a`, `clone`, `pull`.

The remote used was `https://github.com/dhruvh6/git_experiment_20.git`.
